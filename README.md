# victorh.dev Comments

This repository stores blog post comments for **[victorh.dev](https://victorh.dev)** using [Utterances](https://utteranc.es/).

## How It Works

* **Comments as Issues:** Each post that receives a comment automatically generates a corresponding GitHub Issue in this repository via the `utterances-bot` app.
* **Authentication:** Readers sign in with their GitHub account directly on the blog post to leave comments or reactions.
* **Mapping:** Issues are matched to articles by page pathname (`issue-term="pathname"`).

## Moderation & Guidelines

* Comments are subject to the [GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines).
* Please keep discussions constructive, respectful, and relevant to the article.
* Off-topic spam, abusive language, or promotional links will be locked or deleted.

## Repository Structure

* **Issues:** Active and archived comment threads for published articles.
* **Code:** This repository intentionally contains no source code—the website source is maintained separately.
